Dual-User Security Model

Linux DAC Boundary
Security Tier User Account Allowed Capabilities
Agent Tier agent-runner (1001) Runs agy, claude. Holds chmod 600 OAuth creds in /home/agent-runner.
Workspace Tier user (1000) Owns /home/user/workspace. Runs compilers, test scripts, and dev servers.
Host Tier Fastify Gateway ZERO execution. Only forwards commands via E2B API. Protected against all user code.

🛡️ Kernel Defense Guarantee

Even if an attacker uses prompt injection or malicious npm dependencies, the Linux kernel enforces chmod 700 on /home/agent-runner. The process literally cannot access the file descriptor without root privileges, which are completely disabled for the workspace user.
